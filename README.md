## 技术说明

- 全部为单文件 HTML，样式写在 `<head>` 内的 `<style>` 中，无外部依赖、无框架。
- `work3` 严格按作业要求只使用基础排版标签，并实现了后代选择器、链接伪类、并集选择器、ID 选择器、类选择器与伪元素六类选择器。
